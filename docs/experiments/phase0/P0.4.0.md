# Positive control — LR-driven divergence, the gradient-norm gate (P0.4.0)

**What this substudy is.** The two-sided calibration of the **gradient-norm** instrument against the **instability /
divergence** failure mode. Under a deliberately pathological learning rate the grad norm must **fire** (blow up as the
loss runs to non-finite) and under a genuinely-learning baseline it must stay **quiet** (bounded). This is the "minor
mode": the phenomenon is fast and cheap, so the study is the lightest of the modes (seconds–minutes on CPU). The forcing
lever here is the learning rate; the deployment-relevant *data-driven* driver (surprise / shift bursts) is a distinct
substudy ([P0.4.1](P0.4.1.md)).

## Why toy scale is valid here (unlike forgetting)

The P0.3 arc showed toy STL-10 could not host a genuine *forgetting* event, because forgetting is a
representation-learning phenomenon — it needs task structure, a deep well, and respecialization pressure that a tiny
dataset lacks. Divergence is the opposite: an optimization phenomenon. The mechanism is a numerical positive-feedback
loop — too large a step lands the parameters in a higher-curvature region → larger gradients → a larger step → runaway →
loss to inf/NaN. That loop is governed by architecture + optimizer + step-size × local curvature, not by whether the
data carries rich semantic structure (beyond providing the necessary local curvature), so the mechanism the instrument
reads reproduces faithfully at toy scale (if anything, small data → sharper minima → *easier* to trip). Two disciplines
carried from the P0.3 lesson: the critical-LR value is regime-specific and does not transfer numerically to a larger
model — we calibrate the instrument's *response* (does grad norm blow up with / ahead of the loss?), not a universal
threshold; and the healthy arm must exhibit genuine descending-loss learning (P0.1.0 established MAE-on-STL10 trains),
or the quiet grad-norm baseline is a degenerate artifact — the run is gated on confirming it.

## Why MAE — and why **SGD, not AdamW** — is the vehicle

Divergence needs an unbounded loss. MAE's per-patch MSE reconstruction loss is unbounded → it can genuinely blow up to
inf/NaN. SimSiam's negative-cosine loss is bounded in `[-1, 1]` → a too-large LR makes it *collapse*, not diverge (which
is why SimSiam is the collapse vehicle in P0.2 and the wrong one here). MAE is also the project's target backbone.

The optimizer is the second, equally load-bearing choice, and the study established it empirically. The
positive-feedback loop runs through the gradient magnitude feeding back into the step size:

- **SGD** takes a step `≈ LR · ‖g‖`, so a growing gradient directly enlarges the next step — the loop is undamped and
    produces a *gradual* runaway that unfolds over several steps (the regime with observable lead time).
- **AdamW** takes a step `≈ LR · ‖g‖ / (√v + ε) ≈ LR · sign/curvature` — the per-coordinate normalization cancels the
    gradient magnitude out of the step, *damping* exactly that loop. This is now confirmed with a preserved artifact
    (`adamw_seed0`, the AdamW dose-response over `lr ∈ {10⁻³ … 100}`; seed 0): AdamW on this MAE does not give a gradual
    runaway. The grad norm blows to `21 → 4.8×10² → 5.4×10⁵` across `lr = 0.1, 1, 10`, yet the normalized step
    **absorbs** every one — no arm goes non-finite — and only at `lr = 100` does the loss go to NaN, in a *single* step.
    The measured lead time is `None` (no gradual runaway to lead): a knife-edge either way. The sane-LR AdamW reference
    (`lr = 10⁻³`) genuinely learns (loss `1.34 → 0.87`) with a bounded grad norm (peak `1.5`), so the healthy pole is
    real; the point is only that *no* AdamW arm gives the divergence-with-lead behaviour SGD does.

So **SGD (with momentum) is the vehicle that lets the grad-norm instrument *lead* the loss NaN** — the P0.4.0 payoff.
Momentum is held fixed at 0.9 across all arms (LR stays the only lever) and, by accumulating the growing gradients,
lengthens the observable runaway. AdamW's damping is not a nuisance to hide but an *instrument-scope finding*: the
grad-norm leading indicator has usable lead time under SGD-like dynamics, and collapses to a one-step knife-edge under
an adaptive optimizer that normalizes the step — the same "vehicle changes what the instrument can see" lesson as the
MAE-vs-SimSiam loss-boundedness choice.

## Design — one lever (LR), everything else held

Arms of the same MAE over the same IID STL-10 stream (tiny ViT, img 32) from a seed-reset, bit-identical start,
differing only in the learning rate. **Warmup off and grad-clip off on every arm** so (a) LR is the sole difference and
(b) clipping — the standard *mitigation* — cannot mask the blow-up. One healthy arm at a sane LR is the invariant quiet
reference; one PC arm per LR:

| arm | learning rate | prediction |
| -- | -- | -- |
| **healthy** | `1.0` (sane for SGD-mom here) | loss finite & descending; grad norm bounded (no runaway) |
| **PC (diverge)** | swept `{0.1, 0.3, 1, 3, 10, 30}` | past a threshold: loss → non-finite; grad norm explodes first |

> LR dose-response shows a *stability threshold*, not a knife-edge. The interesting operating point is **just past** the
> threshold — a *gradual* runaway over several steps — because a wildly-too-high LR NaNs almost immediately and leaves
> no lead time to observe.

### Two reads that make this more than a smoke test

- **Leading-indicator (the payoff).** Log grad norm *and* loss per step; measure whether the grad-norm blow-up
    **precedes** the loss going non-finite — does grad norm give usable *lead time*? Grad norm is label-free and cheap,
    so a positive lead is what would license it as a live control input.
- **Cross-mode specificity (nearly free).** Read the grad norm on P0.2's SimSiam **collapse** PC (`anti_collapse=false`)
    and confirm it does **not** fire on *collapse* — establishing the instrument is specific to *divergence*, not
    "something bad in general". Free now that the streaming loop is grad-norm-instrumented.

### One cheap ablation

Re-run the fire at a **smaller batch size** (which raises gradient *variance*, a different route than LR's magnitude) to
confirm the fire is not an artifact of the single LR lever. The remaining classical divergence knobs (large init scale,
removed normalization, high momentum, small Adam ε, fp16 overflow) are *the same runaway by a different route* — they
modulate the same `effective step ≈ LR·‖g‖/(√v+ε) × curvature` loop; listed for completeness, not studied.

## What we read (the gate)

- **The two-sided gate.** PC diverges = its loss/grad goes non-finite by the horizon (the unambiguous fingerprint);
    healthy stable = never non-finite and genuinely learns (final loss ≤ 0.9× initial). The headline is the contrast:
    `min diverging-arm peak grad norm / healthy steady peak` — the orders-of-magnitude separation, the direct analogue
    of the collapse RankMe ratio and the forgetting forget-ratio. A healthy grad norm is *bounded, not stationary* (it
    fluctuates with batch noise), so the gate reads this gap, not a fragile peak/median stationarity test.
- **Init-transient handling.** Without warmup the first few steps of *every* arm show a large first-gradient spike; it
    decays, whereas a runaway grows. Steady-state stats and the lead-time spike search start after a short `init_skip`
    so that transient is never mistaken for a blow-up.
- **Lead time** = (step of first non-finite loss) − (step grad norm first crosses the blow-up level, after `init_skip`);
    `> 0` is the win.
- **Dose-response** = the LR at which divergence first appears, and that the runaway speeds up monotonically above it.

## Findings

Seed 0 (STL-10, tiny MAE, img 32, SGD momentum 0.9, warmup & clip off); reproduced at seed 1.

- **Two-sided gate: PASS.** Healthy (`lr=1`) stays finite and learns (loss `1.34 → 0.996`), with a bounded grad norm
    (steady median `0.026`, peak `0.44`). The top PC (`lr=30`) goes **non-finite at step 4** with peak grad norm
    `4.1×10¹²`. The portable verdict is the **separation**: every diverging arm clears the healthy peak by
    `≥ min_separation = 100×`. The single headline contrast the gate prints (`1.2×10⁶×` here) is *illustrative, not
    portable* — it is `min(diverging-arm peaks) / healthy peak`, and each arm's peak is the max over its *finite* steps
    only, so whichever arm NaNs earliest records the fewest steps and the lowest peak, and the `min` then picks that
    arm. The number is therefore truncation-sensitive (it swings `3.4×10⁴× → 1.2×10⁶×` across the seed/batch runs of the
    *same* phenomenon) even though the `≥100×` verdict is rock-solid.
- **Dose-response with a real threshold.** `lr ≤ 1.0` stable; **threshold at `lr = 3.0`** (NaN@step 8), then `lr=10`
    (NaN@5), `lr=30` (NaN@4) — the runaway **speeds up monotonically** with LR. Grad norm climbs
    `≈0.02 → 3 → 25 → 187 →   6×10⁸ → NaN` over the threshold arm.
- **Leading-indicator payoff: 5 steps of lead.** At the just-past-threshold operating point (`lr=3`), the grad-norm
    blow-up crosses the level at **step 3** while the loss does not go non-finite until **step 8** — the label-free grad
    norm gives usable warning *before* the loss fails.
- **Cross-mode specificity.** P0.2's forced-collapse SimSiam PC rides its loss toward the `−1` constant-solution floor
    (genuine collapse) yet keeps its grad norm **bounded** (peak `~1.9–2.5` across seeds 0/1/2, *never* non-finite;
    artifact `collapse_specificity/`) — grad norm does **not** fire on collapse, seed-robustly and orders of magnitude
    below the divergence scale. Specificity is established against a second null too — a *benign in-regime shift*: the
    P0.4.1 distributional-OOD non-fire shows the grad norm correctly ignores a structure-destroying-but-in-range burst.
    Against the third sibling mode, *forgetting* (P0.3), it is now shown too (artifact `forgetting_specificity/`, seeds
    0/1/2): on the P0.3.9 seed-stable SSL-MAE crater — where every seed genuinely forgets (PC BWT `−0.065…−0.075`) — the
    phase-B grad norm peaks at only `~4–8` and stays finite, ~4 orders of magnitude below the divergence scale, and does
    not even separate the forgetting PC from the healthy arm (both `~5–7`). Forgetting is a slow representation drift,
    not an optimization instability, so the divergence instrument is correctly blind to it. So the instrument is *shown*
    specific to divergence against all three of its sibling nulls — collapse, an in-range shift, and forgetting.
- **Not a batch-size artifact.** Re-running at `batch_size=16` (higher gradient variance) reproduces the **same
    threshold** (`lr=3`) and the **same 5-step lead** — *identical across seeds 0/1/2* (artifact `batch16_seeded/`),
    with the healthy arm still learning (final ≤ `0.79×` init) and the gate passing every seed. The fire is a property
    of the LR lever, not the batch size. The separation swings `10⁶`–`10⁷×` across seeds but is always ≫ the `100×` bar
    — the same truncation/device-sensitivity the headline contrast has (only the `≥100×` verdict is portable). (The
    seeded reruns are `device=hpu`; the original CPU `batch16_seed0` at the full sweep agrees on threshold `3` and lead
    `5`.)
- **A narrow safe band — the healthy LR sits close to the threshold.** The healthy reference is `lr=1` and the threshold
    is `lr=3`: a **3× margin**, sub-decade in LR. Moreover `lr=1` is *not* the best-learning arm — `lr=0.1` descends
    further (final `0.66×` init vs `lr=1`'s `0.74×`), so the chosen healthy LR is a deliberately near-threshold
    reference (warmup/clip off), not the best learner. Without warmup/clip the SGD-MAE therefore has a thin corridor
    between "learns well" and "diverges" — a concrete toy-scale operating-envelope datum, and a positive framing of
    *why* the leading indicator matters (a small LR overshoot is easy to hit).

## Insights

- **The non-finite event is the divergence fingerprint; the grad-norm blow-up is its *leading indicator*.** The gate
    fires on the unambiguous loss/grad → inf/NaN event; the value of the grad norm is that it *precedes* that event,
    which is what a live label-free monitor would exploit (the `metrics.md` leading-indicator link, applied to
    instability).
- **Optimizer choice bounds what the instrument can see.** SGD's undamped step exposes the gradual runaway the grad norm
    can lead; AdamW's normalized step damps it to a one-step knife-edge with no lead time. A grad-norm early-warning
    signal is therefore trustworthy under SGD-like dynamics and largely mute (as a *leading* indicator) under an
    adaptive optimizer — a scope caveat, not a universal property.
- **Lead time is not free — it is inversely coupled to the step-size overshoot (the operating envelope).** The runaway
    is a *geometric* growth in the gradient: with SGD the step is `≈ LR·‖g‖`, so near a bowl of local curvature `λ` a
    step multiplies the gradient by `≈ |1 − LR·λ| > 1` once `LR·λ` overshoots the stability edge. The larger that
    overshoot, the larger the per-step multiplier, so the *fewer* steps from a detectable grad-norm blow-up to the loss
    NaN — exactly the monotone speedup in the dose-response (NaN@8 → @5 → @4 as `lr = 3 → 10 → 30`). So the usable lead
    time is longest **right at threshold** and shrinks toward zero as the instability worsens; the wildly-too-high-LR
    SGD limit meets the AdamW-normalized limit — **both are a no-lead knife-edge**. The leading indicator buys the most
    warning precisely when the divergence is mildest. Two consequences: the absolute lead-in-steps (like the critical
    LR) is regime-specific and does **not** transfer to a larger model — we calibrate that the ordering *exists*, not a
    portable number; and the deployment-relevant way to characterise the lead-time-vs-severity tradeoff is to hold the
    LR fixed and vary a *data* shock's magnitude ([P0.4.1](P0.4.1.md)), the severity axis one cannot tune away in
    production.
- **A healthy grad norm is bounded, not stationary.** It fluctuates with batch noise around a low band; the divergence
    signature is the *unbounded monotone growth*, read cleanly as the orders-of-magnitude contrast against the healthy
    peak (and the no-warmup init transient, which decays, must be excluded so it is not mistaken for a blow-up).

## Build

The streaming loop had no grad-norm plumbing (it only *clipped*). Added, kept lean and reused live in Phase-1:

1. **Grad-norm capture** in `cafl4ds/loop.py::StreamingLoop._update` — the global L2 grad norm computed **pre-clip**
    (visible even with a clip on), returned in an `UpdateStats(loss, grad_norm, finite)` record with a non-finite
    guard.
1. **Divergence stop** — the loop records the first non-finite step, logs it, and **stops** (no stepping on NaN params;
    the closing health read is skipped on a diverged model).
1. **Per-step trace** — `RunLogger.log_loss` now carries `grad_norm` + `finite` on each loss record (the
    leading-indicator read needs the full per-step series).
1. **Harness + config + gate** — `scripts/positive_control_instability.py` + `configs/positive_control_instability.yaml`
    (with `configs/optim/sgd.yaml`), running the healthy arm + the PC LR sweep in one session and evaluating the
    two-sided contrast + divergence + lead-time gate.

## How to run

The whole dose-response runs in one session (seconds–minutes on CPU):

```bash
uv run python scripts/positive_control_instability.py seed=0
```

Batch-size ablation, a finer sweep, or a single operating point:

```bash
uv run python scripts/positive_control_instability.py batch_size=16
uv run python scripts/positive_control_instability.py 'lr_sweep=[1,2,3,4,6]'
```

The AdamW pole (the vehicle-finding counterfactual — the `adamw_seed0` artifact; grad blows up but the normalized step
absorbs it, one-step NaN only at `lr=100`, no lead):

```bash
uv run python scripts/positive_control_instability.py optim=adamw lr_healthy=1e-3 'lr_sweep=[1e-3,0.01,0.1,1,10,100]'
```

Cross-mode specificity reuses the (now grad-norm-instrumented) collapse harness — read the `grad_norm` field of its
per-step loss records and confirm the collapse PC's stays bounded:

```bash
uv run python scripts/positive_control.py epochs=8   # inspect simsiam_pc.jsonl grad_norm (bounded, never non-finite)
```

Read: the LR at which the PC arm's loss first goes non-finite and its grad norm blows up while the healthy arm holds;
the per-step trace for the lead time between the grad-norm blow-up and the loss NaN at the just-past-threshold LR; and
the collapse PC's grad-norm trace staying bounded while its RankMe collapses.
