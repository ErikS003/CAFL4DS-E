# Positive control — the forgetting gate, and making forgetting *real* (P0.3.0)

This substudy opens the **forgetting** failure mode (after collapse → P0.2.x). The collapse gate says nothing about
whether the *forgetting* detectors work, so P0.3 calibrates them under the same two-sided discipline: a deliberate
catastrophic-forgetting event must make the instruments **fire**, while a matched no-forgetting control keeps them
**quiet**. P0.3.0's job is the hard first step — construct a forgetting positive control that is actually real, then
read which instruments fire on it. The healthy arm is a single **replay** toggle away from the PC: P0.3.0 delivers not
just a firing positive control but the complete, passing two-sided forgetting gate on one distinct-task corner (PC
craters, healthy holds).

The forgetting instruments already exist from P0.1.0 — per-era accuracy matrix, Backward Transfer (Lopez-Paz & Ranzato
2017), Forgetting Measure (Chaudhry et al. 2018), and backbone CKA/cosine drift. P0.3.0 *calibrates* them; it does not
build them.

## The vehicle — split-task MAE with a replay toggle

The failure-mode architecture is **MAE** (collapse-resistant; its degradation mode is forgetting/overspecialization).
The vehicle is a **split-task** stream: the data classes are partitioned into two disjoint tasks, era **A**
(`task_a_classes`) and era **B** (`task_b_classes`). Each arm trains in two phases over the same content from scratch,
differing only by a single **replay** toggle:

- **PC (forgets)** — phase A trains on task A only, then phase B trains on task B **only**. With no revisits to A, the
    representation respecializes to B.
- **healthy (holds)** — identical phase A, then phase B **replays A** (trains on A ∪ B). The replay toggle is the *only*
    difference; the seed is reset before each arm so phase A is bit-identical, isolating forgetting as the cause. This
    mirrors the collapse harness's single-toggle discipline (`anti_collapse`) — here the toggle is replay.

Forgetting is read from the two-phase accuracy matrix `R[i][j]` = accuracy on task `j` after phase `i` (phase 0 = after
A, phase 1 = after B): `BWT = R[1][0] − R[0][0]` (negative ⇒ task A eroded) and `FM = R[0][0] − R[1][0]`. Each task is
probed as its **own** |task|-way classification within its own held-out classes (random baseline `1/|task|`), so the
probe has real headroom — unlike a saturating 2-class probe. Backbone drift (referenced to the post-A representation, so
it measures phase-B movement) and an MAE-native reconstruction readout are read alongside.

## Making forgetting real — what did *not* work

Three negative results are a calibration finding in their own right:

1. **The synthetic smoke source cannot host this mode — and it is a plumbing check, not an experiment vehicle.** Phase 0
    ships a network-free `SyntheticSource` (`cafl4ds/data/sources.py`, config `configs/data/synthetic.yaml`): it
    generates *class-structured Gaussian images* — each class is a blob of pixels scattered (small per-pixel noise)
    around its own distinct random pattern. It exists only to smoke-test the loop **offline** — confirm the accuracy
    matrix + BWT/FM + drift all populate end-to-end without a dataset download — and **every result in this study uses
    STL-10**, never synthetic. The catch is that those Gaussian blobs are *linearly separable in raw pixel space
    itself*, before any representation is learned, so the transfer probe pins at **1.0 even on a random-init backbone**
    (it is reading trivially-separable pixels, not learned features). With the probe saturated there is no headroom for
    task A to sit below and no learned specialization for phase B to erode: forgetting is unmeasurable — an
    *instrument-saturation* boundary, not evidence about forgetting. The mode needs a dataset whose task is
    *learnable-but-non-trivial* (real headroom over the random-init floor) — hence STL-10 and beyond.
1. **Toy MAE does not forget under a transfer probe — at any scale.** An arbitrary class split (`{0–4}` vs `{5–9}`),
    even with an escalated MAE on the Gaudi HPU (embed 256, depth 8, img 64, 300 epochs/phase, full STL-10 split),
    produced *no* forgetting: the PC arm's task-A accuracy rose during B-only training (0.560 → 0.630, BWT +0.070), the
    healthy arm rose more (→ 0.677), and drift was indistinguishable (cka 0.032 vs 0.030). The mechanism is structural,
    not a horizon problem: (a) a *random-init* ViT already linear-probes to ~0.53 on the 5-way task, so the probe reads
    random-projection quality, not what MAE learned (300 epochs moved it only +0.03); (b) MAE reconstruction learns
    broadly transferable natural-image structure, so training on B *helps* A too — there is no discriminative task
    boundary for B to overwrite. This may also be an effect of having too much model capacity for the complexity of the
    dataset. Escalating scale (other than data complexity) cannot fix this.
1. **Backbone drift is not a reliable forgetting indicator at toy scale.** `cka_drift` separates only weakly and
    near-threshold (a coin-flip), and `cosine_drift` *inverts* (larger in the healthy arm). The plan's hoped-for
    label-free leading indicator does not cleanly track forgetting here.

## Making forgetting real — the fair regime

The lever that worked at this scale is **task distinctness**. Splitting STL-10 into visually non-transferable groups —
task A = **vehicles** `{airplane 0, car 2, ship 8, truck 9}`, task B = **animals** `{bird 1, cat 3, dog 5, horse 6}` —
gives a genuine forgetting event: training on animals actively erodes the vehicle representation, because the two share
far less low-level structure. Same escalated MAE, same horizon; only the split changes.

## Findings

> **⚠ Revised by [P0.3.2](P0.3.2.md):** this single-seed "pass" did not survive multi-seed / precise-probe replication —
> 0/5 seeds forget robustly at this corner (the −0.071 was a probe-noise draw). The BWT/FM *instruments* are sound; toy
> STL-10 vehicles/animals simply hosts no robust forgetting event. Calibration escalates to CIFAR-100
> ([P0.3.4](P0.3.4.md)). The findings below stand as toy-scale *characterisation*, not a calibrated gate.

On the vehicles/animals split (escalated MAE, HPU, 300 epochs/phase), both arms train a bit-identical phase A that
genuinely learns task A (vehicles **0.521 → 0.617**, +0.096 over the random-init floor — nearly 3× the arbitrary split's
+0.03). Then:

| Signal | PC (animals-only) | healthy (A-replay) | verdict |
| -- | -- | -- | -- |
| **task-A (vehicles) probe** | 0.617 → **0.546** | 0.617 → 0.596 | crater −0.071 vs −0.021 |
| **BackwardTransfer** | **−0.071** | −0.021 | fires (≤ −0.05) |
| **ForgettingMeasure** | **+0.071** | +0.021 | fires (≥ 0.05) |
| **forget ratio (PC/healthy FM)** | — | — | **3.4×** contrast |
| **cka_drift** (phase B) | 0.051 | 0.023 | *reported* — weak (~2×, near-threshold) |
| **cosine_drift** | 0.256 | 0.318 | *reported* — **inverted** |
| **MAE recon-A rise** | −0.027 | −0.086 | *reported* — gap **+0.059** |

Three conclusions:

- **The forgetting positive control is real, and the transfer-probe metrics are the reliable signal.** BWT/FM fire on
    the PC arm with a clean ~3.4× contrast against the healthy arm, which holds. This is the P0.3.0 acceptance result.
- **At this scale, drift is demoted to a reported observation.** It is not a trustworthy standalone forgetting detector
    at this scale (cka near-threshold, cosine inverted), so it is measured and written to the artifact but does **not**
    gate — the forgetting analogue of P0.2's "read at the projector only" instrument-scoping conclusions.
- **The MAE-native reconstruction signal corroborates via *relative retention*.** The PC retained held-out task-A
    reconstruction much worse than the replay arm (rise −0.027 vs −0.086; gap +0.059). It separates cleanly, but note it
    is "improved less," not absolute degradation — both arms' recon improves, and its absolute magnitude is dominated by
    task difficulty (vehicles are simply easier to reconstruct than animals). Reported and corroborating, not gated.

The crater is genuine but **modest and near the toy-scale noise floor**: two identical-regime runs gave PC craters of
−0.050 and −0.071 (and cka drift 0.047 vs 0.051), which is why the gate rests on the robust BWT/FM contrast rather than
an absolute drift or recon threshold.

## The gate

The hard pass criterion (`_evaluate_forgetting_gate`) rests entirely on the transfer-probe forgetting metrics: phase A
learned task A (gain ≥ `learn_min`), the PC craters (`BWT ≤ −bwt_fire`, `FM ≥ fm_fire`), the healthy arm holds
(`|BWT| ≤ bwt_quiet`), and the PC forgets at least `min_forget_ratio`× the healthy arm's forgetting (the replay-toggle
contrast). Backbone drift and the MAE-native recon gap are written to the artifact as reported observations but do not
gate, per the findings above. A non-passing run exits non-zero, matching the collapse-gate discipline.

## How to run

The harness is `scripts/positive_control_forgetting.py` (config `cafl4ds/configs/positive_control_forgetting.yaml`); it
runs both arms in one session and writes `comparison.json` = `{gate, pc, healthy}`. The fair regime is the escalated MAE
on the Gaudi HPU (see `docs/developing.md`):

```bash
./scripts/run_gaudi_dev.sh -m /mnt/stl10 gaudi-env-cafl4ds:latest 0 \
    python scripts/positive_control_forgetting.py device=hpu \
    'task_a_classes=[0,2,8,9]' 'task_b_classes=[1,3,5,6]' \
    encoder.embed_dim=256 encoder.depth=8 encoder.num_heads=8 img_size=64 \
    ssl.decoder_dim=128 ssl.decoder_depth=4 ssl.decoder_heads=4 \
    epochs_a=300 epochs_b=300 batch_size=128 probe=linear recon_masks=16
```

A fast network-free CPU invocation
(`uv run python scripts/positive_control_forgetting.py epochs_a=2 epochs_b=2 max_per_class=40 batch_size=16 img_size=32 probe=knn knn_k=5 support_per_class=10 query_per_class=10`)
exercises the plumbing only — it will FAIL the gate (toy MAE does not forget), by design. The `task_a_classes` /
`task_b_classes` lists are the correlation/distinctness knob: the arbitrary `{0–4}`/`{5–9}` split is the documented
*negative* control (no forgetting); the vehicles/animals split is the *fair* regime that fires.
