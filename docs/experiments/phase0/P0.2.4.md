# Positive control — false-positive stress on the quiet side (P0.2.4)

[P0.2.2](P0.2.2.md) mapped *where each collapse instrument fires and where it stays quiet* across regimes, and
[P0.2.3](P0.2.3.md) closed the *fire* side of off-diagonal covariance with a redundancy vehicle. But every P0.2.x run so
far varies how the **PC and healthy arms separate** — the healthy arm has always been a *well-behaved* SimSiam. P0.2.4
turns the calibration around: it deliberately stresses the **quiet side**, pushing a *genuinely-healthy* representation
into regimes that **superficially resemble collapse**, and maps where instruments **false-fire** — then, via the
**Option B** ablation (a matched collapse-pole per regime), splits each false fire into a genuine in-regime blind spot
vs. an eval-set artifact.

## Why this exists (what P0.2.2 left open)

Everything E1–E4 varies is how the collapse (PC) and healthy arms *separate*; none deliberately stresses the quiet side
with a *healthy-but-atypical* representation. So the measured **false-positive rate** of the suite is essentially
untested — the "healthy" arm is always a canonical, well-behaved SimSiam. In the coupled active-learning loop this is
the failure mode that actually hurts: a false fire re-aims the streaming selection filter at a non-problem, so a
detector that fires on a legitimately low-rank-but-healthy representation is *actively harmful* — arguably worse than a
missed detection, which merely fails to intervene.

## Scope — healthy-only, three atypical-but-healthy regimes

The vehicle is the intact SimSiam (`anti_collapse=True`) from P0.2.1/P0.2.2, pushed into regimes that mimic a collapse
fingerprint without being collapse. The Option B ablation also compares against a regime-matched forced-collapsed model.
The instrument set and both surfaces (backbone + projector) are unchanged, so readings stay directly comparable to
P0.2.2's activation map. We consider the following stressors / regimes:

- **Low-diversity data** — few classes / near-duplicate eras: a *legitimately low-rank but healthy* representation, the
    natural false-fire risk for RankMe and `offdiag_cov`. Driven by the existing stream knobs — `stream.class_order` (a
    class subset), `stream.max_train_per_class` (per-class volume), and the E3 `stream.block_size` correlation knob — no
    new data code.
- **Heavy augmentation** — over-strong views: a healthy representation with genuinely lower alignment/uniformity, the
    natural false-fire risk for the uniformity/alignment pair.
- **Deliberate undertraining** — the sub-base-LR single-pass corner E4 already *grazes* (RankMe @ proj dips below the
    bar at 0.25×/0.5×); P0.2.4 extends it to confirm no instrument reads "collapse-like" on an undertrained-but-healthy
    arm.

## Which instrument is at risk in which regime?

The regimes are chosen so each targets the *specific* instrument most likely to mistake it for collapse. The predictions
(to be confirmed or refuted, mirroring P0.2.2/P0.2.3's theory-first table):

| Regime | Instrument at risk | Why it superficially resembles collapse | Prediction |
| -- | -- | -- | -- |
| **Low-diversity data** | RankMe (both surfaces), `offdiag_cov` | few classes / near-duplicate eras genuinely lower the effective rank and can raise inter-feature redundancy | **Stays quiet** — a healthy low-rank representation is *not* a collapse; if RankMe fires this is a documented false-positive boundary. |
| **Heavy augmentation** | uniformity / alignment @ proj | over-strong views spread the embeddings and weaken positive-pair agreement, moving uniformity/alignment | **Stays quiet** — the pair should track *healthy* geometry; a spurious uniformity fire would mark a boundary. |
| **Deliberate undertraining** | RankMe @ proj (the single-pass detector) | an undertrained projector has not expanded, so its geometry is immature but *not* collapsed | **Stays quiet** — E4 already shows the healthy arm reads below the fire bar here; confirm it never crosses. |

A regime where an instrument *does* cross its bar is not a failure — it is a **known false-positive boundary**, a
genuine calibration result to document (not to engineer away).

## Methodology — the quiet verdict

The distinctive twist is that there is **no PC arm to separate from**, so the two-sided "fires vs quiet" verdict of
P0.2.2 does not apply verbatim. The operationalization keeps the study inside the **scale-invariant separation-ratio**
framework the whole P0.2 series rests on (P0.2.1/P0.2.2 established that *absolute* thresholds do not transfer across
scale/regime, which is exactly why the fire bars are ratios/gaps, not floors):

- **(Option A): Paired against a canonical healthy reference.** Each stressor run pairs an **atypical-healthy** *test*
    arm (`anti_collapse=True` + the stressor overrides) against a **canonical-healthy** *reference* arm (the certified
    IID×40-epoch base config, `anti_collapse=True`), run in the same session for a matched scale. The existing
    `metric_envelope` machinery is reused **unchanged**, feeding the atypical arm in the "PC" slot: a **false fire** =
    the atypical-healthy arm separates from the canonical healthy *in the collapse direction* by ≥ its fire bar (ratio ≥
    2.0, gap ≥ 0.5, ≥ 4 seeds). The verdict is **inverted** relative to P0.2.2: the run **passes** iff **no** instrument
    fires (the quiet side holds). Because this is a *quiet*-side test, the robust aggregate is the **max**-across-seeds
    separation (the seed closest to firing), the mirror of the fire test's min-across-seeds — see Acceptance criterion.
    **Comparability caveat (low-diversity).** A class-subset test arm is evaluated on a smaller probe query set than the
    10-class reference, which structurally caps effective rank. To keep the reference an apples-to-apples healthy pole,
    a low-diversity cell can (a) restrict the reference arm to the *same* class subset, and/or (b) add a *matched* PC
    arm in the stressed regime as an explicit collapse pole, and check the atypical-healthy reading sits nearer the
    healthy pole than the collapse floor. This is the one regime where a bare paired-ratio can mislead — and it is
    exactly what the **Option B ablation** (below) does, resolving each low-diversity false fire into artifact vs.
    genuine blind spot.

- **(Option B): Paired against a regime-matched forced-collapse arm.** Option A's paired verdict compares the
    atypical-healthy arm against the *canonical* (out-of-regime) reference. For low-diversity that reference is a
    10-class arm while the atypical arm is evaluated on a rank-capped 2-class probe, so a RankMe "false fire"
    **conflates the model with the eval set** — the one place the bare paired-ratio is weak. Option B resolves this by
    adding a **third arm per run**: a matched *forced-collapse* arm (`anti_collapse=False`) in the **same stressed
    regime** as the atypical arm (same `stressor.overrides`). Because the collapse pole and the atypical arm now share
    the *identical* stressed eval set, the eval-set cap affects both equally and **cancels in the ratio**.

Two readouts disambiguate each Option-A fire, per `(instrument × surface)`:

- **In-regime discrimination (confound-free)** — feed the collapse-in-regime arm into the `pc` slot *against the
    atypical-healthy arm*: `metric_envelope(collapse_in_regime, atypical)`. Does a *genuinely collapsed* arm still
    separate from the atypical-healthy arm **within** the regime? If it **fires**, the instrument keeps its
    discriminative power in-regime, so the Option-A fire was a reference / eval-set artifact; if it **stays quiet**, the
    instrument cannot tell collapse from healthy in that regime — a **genuine in-regime blind spot**.
- **Position on the [collapse-pole, canonical-healthy] axis** — the linear coordinate `pos = (a − c) / (h − c)` of the
    atypical reading `a` between the collapse pole `c` and the canonical-healthy pole `h` (direction-agnostic: `pos = 1`
    at healthy, `pos = 0` at collapse). `pos > 0.5` means the atypical arm reads *nearer healthy than collapse*. The `h`
    pole is out-of-regime, so `pos` still carries the eval-set caveat for low-diversity — it is the *in-regime
    discrimination* readout, not `pos`, that is the confound-free arbiter there.

## Implementation additions (code)

The measurements, surfaces, and envelope all exist; P0.2.4 adds the healthy-vs-healthy harness and the two stressor
knobs not yet exposed:

1. **False-positive-stress harness** — a sibling entry point (`scripts/false_positive_stress.py`) rather than a change
    to the certified `scripts/positive_control.py`. It runs a canonical-healthy reference arm + an atypical-healthy
    test arm (both `anti_collapse=True`, the stressor applied only to the test arm via per-arm overrides), feeds
    `metric_envelope(atypical, reference)`, and emits the **inverted (quiet) verdict** — pass iff no instrument fires.
    Writes the same `{run, gate, envelope}` `comparison.json` the promotion convention tracks.
1. **Stressor config group** — `cafl4ds/configs/stressor/` with `low_diversity.yaml` (class subset + reduced per-class
    volume), `heavy_aug.yaml` (augmentation-strength up), and `undertrained.yaml` (the E4 `epochs=1`, sub-base-LR
    corner). Selected on the CLI; the harness applies it to the test arm only.
1. **Augmentation-strength exposure** — thread a strength knob (`min_scale` and jitter magnitude) from the SSL config
    through `build_simsiam`/`build_barlow` into `make_ssl_augment`, so `heavy_aug` is a config override rather than a
    code edit. Currently `make_ssl_augment(img_size)` is called with defaults inside the factory.
1. **Class-subset stressor** reuses the existing `EraStream.class_order` knob (a class subset is already supported at
    both `iid` and `class_blocked` orders) — no data-code change.
1. **Option B is gated** behind `collapse_pole=true`, leaving the Option-A run byte-identical when off.

## Acceptance criterion

**No instrument fires on any healthy-but-atypical regime** — the quiet side holds under the paired verdict. For a
*quiet*-side test the conservative statistic is the **max**-across-seeds separation (the seed *closest* to firing — the
mirror of the fire test's min-across-seeds): the quiet side holds only if even the worst seed stays below its bar. If an
instrument *does* fire, the regime is documented as a **known false-positive boundary** of that instrument (itself a
useful calibration result), not engineered away, and compared against the firing behavior in the Option B scenario: **A
fires & B fires** ⇒ the Option-A false fire is a reference/eval-set artifact (the instrument works in-regime); **A fires
& B quiet** ⇒ a genuine in-regime blind spot.

## Option A findings

Across 4 seeds per stressor at the 40-epoch IID STL-10 reference corner (atypical arm in the PC slot; bars ratio ≥ 2.0,
gap ≥ 0.5). **The suite is not false-positive-free at this toy scale** — every atypical-but-healthy regime trips at
least one detector, so each is a documented false-positive boundary (the acceptance criterion's "if one does, document
it" branch). Robust map (**max**-across-seeds separation — the worst, closest-to-firing seed; **FALSE FIRE** = a
standalone instrument clears its bar even there):

| Stressor | False-fires (instrument @ surface, max-across-seeds) | Stays quiet | Per-seed quiet |
| -- | -- | -- | -- |
| **Low-diversity data** | rankme @ backbone (2.07×), rankme @ proj (2.44×), offdiag_cov @ backbone (3.14×), uniformity @ proj (0.57 gap) | variance (both), offdiag_cov @ proj, uniformity @ backbone | 1 / 4 |
| **Heavy augmentation** | mean_feature_var @ backbone (3.55×, worst seed only) | rankme (both), offdiag_cov (both), uniformity (both), variance @ proj | 3 / 4 |
| **Deliberate undertraining** | offdiag_cov @ backbone (5.06–38.8×, **all 4 seeds**) | rankme (both), variance (both), uniformity (both), offdiag_cov @ proj | 0 / 4 |

1. **`offdiag_cov` @ backbone is the dominant false-positive liability** — it false-fires under *both* undertraining
    (robustly, 5–39× across all four seeds) and low-diversity data (3.1×). An undertrained or low-diversity backbone
    has genuinely correlated features (redundancy not yet reduced), which the instrument reads as redundancy collapse.
    Crucially, **`offdiag_cov` @ projector stays quiet in all three stressors.** Read against [P0.2.3](P0.2.3.md) —
    where `offdiag_cov` *fires for the right reason* at the projector under a redundancy vehicle — this closes a clean
    rule: **read off-diagonal covariance at the projector surface only**; its backbone reading is false-alarm-prone.
    The two studies together fully characterize the instrument (projector = trustworthy on both sides; backbone =
    FP-prone).
1. **RankMe survives undertraining but not low-diversity data.** It stays quiet under undertraining (the E4-motivated
    worry — refuted) and heavy augmentation, but false-fires on low-diversity data at *both* surfaces (2.07× backbone,
    2.44× proj) — its predicted natural risk (a genuinely low-rank healthy representation). **Caveat:** the
    low-diversity test arm is evaluated on a 2-class probe set that structurally caps effective rank, so this reading
    conflates the model with the eval set (the comparability caveat above). It flags a real Phase-1 concern (era eval
    sets are few-class) but is partly a data artifact, not a pure model false-fire — the one regime where the bare
    paired-ratio is weakest. The **Option B** ablation (below) resolves the split cleanly: at the *projector* this fire
    is a confirmed eval-set artifact (the matched collapse pole still separates 3–4× in-regime), while at the
    *backbone* it is a genuine in-regime blind spot.
1. **Heavy augmentation is the most robust regime** — 3/4 seeds fully quiet; the lone boundary is `mean_feature_var` @
    backbone on the worst seed (3.55×, mean 2.23×), and the predicted at-risk pair (uniformity/alignment) stayed quiet.
    This re-confirms P0.2.2's E8 verdict that variance is the noisiest instrument and **must never be a standalone
    gate** — a bad draw grazes even a healthy heavy-aug arm.
1. **The projector surface is again the trustworthy core.** Every robust false fire sits at the *backbone*
    (`offdiag_cov` @ bb, variance @ bb) or in the eval-set-confounded low-diversity regime; at the projector, variance
    and `offdiag_cov` stay quiet across all three stressors (only uniformity @ proj grazes, in low-diversity). A third
    independent vindication — after P0.2.2's sensitivity map and P0.2.3's fire-side — of reading the collapse suite at
    the projector.

The clean, matched-eval-set conclusions are undertraining and heavy augmentation (both arms 10-class); low-diversity
carries the eval-set caveat. That caveat is what the **Option B** ablation below closes.

## Option B findings

The matched collapse-pole sweep (3 regimes × 4 seeds, `collapse_pole=true`) resolves **every** Option-A false fire into
one of two clean verdicts. "B" is the in-regime discrimination `metric_envelope(collapse_in_regime, atypical)` reported
as **min**-across-seeds (the fire test's robust statistic — does the collapse pole separate even on its weakest seed?);
`pos` is the atypical arm's position on the `[collapse-pole, canonical-healthy]` axis (`1` = healthy, `0` = collapse):

| Regime | Option-A fire (instrument @ surface) | B: collapse-vs-atypical in-regime | atypical `pos` | Verdict |
| -- | -- | -- | -- | -- |
| **Low-diversity** | rankme @ **proj** (2.44×, 3/4) | **fires 4/4** (3.03–4.33×) | ~0.4 | **eval-set artifact** — instrument sound in-regime |
| **Low-diversity** | uniformity @ **proj** (0.57, 1/4) | **fires 4/4** (0.79–0.96 gap) | ~0.6 | **eval-set artifact** — instrument sound in-regime |
| **Low-diversity** | rankme @ **backbone** (2.07×, 2/4) | **quiet 0/4** (≤ 1.20×) | ~0.1 | **genuine in-regime blind spot** |
| **Low-diversity** | offdiag_cov @ **backbone** (3.13×, 2/4) | mixed (3/4, one A-seed quiet) | ~0.7 | unreliable at backbone |
| **Undertraining** | offdiag_cov @ **backbone** (5–39×, 4/4) | mixed (2/4, 0.64–2.36×) | −0.6…0.6 (≈ collapse pole) | **genuine backbone saturation** (not an artifact — same eval set) |
| **Heavy aug** | mean_feature_var @ **backbone** (3.55×, 1/4) | quiet on the A-seed | ≈0 on that seed | noise (variance, non-standalone) |

1. **Every projector-surface false fire is an eval-set artifact, not a blind spot — the disambiguation Option B was
    built for.** Both Option-A projector fires are exonerated: within the 2-class low-diversity regime the *matched*
    collapse pole separates from the atypical-healthy arm on **all four seeds** — RankMe @ proj by 3.0–4.3×, uniformity
    @ proj by 0.79–0.96 gap — so both instruments retain full discriminative power there. Option A fired only because
    it compared the rank-capped 2-class atypical arm against the higher-rank 10-class *reference*; the fire is the
    eval-set cap moving the out-of-regime baseline, **not** the atypical model resembling collapse. This closes the
    low-diversity caveat: **RankMe @ projector is not fooled by low-diversity data** — the Phase-1 exposure is the
    few-class *era eval set*, fixed by matched-class evaluation (**now built and directly confirmed**, see below), not
    the instrument.
1. **Every backbone false fire is genuine.** RankMe @ backbone under low-diversity is a real in-regime **blind spot**:
    the matched collapse pole stays quiet on all four seeds (≤ 1.20×) and the atypical arm sits *at* the collapse pole
    (`pos ≈ 0.1`) — the backbone simply cannot order collapse vs. healthy in that regime. `offdiag_cov` @ backbone
    under undertraining — which shares the **same 10-class eval set**, so no eval-set confound exists — is genuine
    backbone **saturation**: at `epochs=1` neither arm has decorrelated, so the collapse pole separates from the
    atypical arm on only 2/4 seeds and the atypical arm itself sits at/near the collapse floor (`pos` −0.6…0.6). This
    is a true liability, not an artifact.
1. **The projector/backbone split is now mechanistic, not heuristic.** Option A observed that robust false fires cluster
    at the backbone; Option B *explains why* — the projector's apparent fires are eval-set artifacts of instruments
    that still discriminate collapse in-regime, while the backbone's fires are genuine losses of discriminative power.
    This upgrades P0.2.4's rule from an empirical pattern to a confirmed one: **read the collapse suite (RankMe,
    off-diagonal covariance, uniformity) at the projector only.** The variance @ backbone heavy-aug graze is again just
    noise (B erratic on the very seed A grazed), reconfirming variance is never a standalone gate.

## Matched-class evaluation — the low-diversity fix, built and confirmed (A2)

Option B *diagnosed* the low-diversity RankMe fire as an eval-set-cap artifact (the rank-capped 2-class atypical arm
compared against a higher-rank 10-class reference), but the fix — evaluating both arms on the **same** class span — was
only asserted. It is now implemented and demonstrated. The mechanism is `EvalSets.restrict_to_classes(...)` (in
`data/streams.py`): the canonical reference arm still *trains* on all ten classes, but its monitor is *evaluated* on the
atypical arm's few-class subset, so RankMe's structural class-count cap is matched across the two arms and the artifact
cancels by construction (enabled via `match_eval_classes=true`, a no-op for stressors that do not subset classes).

Re-running the low-diversity Option-A cell across the four seeds with matched-class eval **removes the RankMe false fire
entirely, at both surfaces, on every seed** — the direct confirmation of Option B's inference:

| RankMe surface | max-across-seeds separation (bar 2.0) | Option-A per-seed fires |
| -- | -- | -- |
| **@ proj** | **2.44× → 1.82×** (below bar) | 3/4 → **0/4** |
| **@ backbone** | 2.07× → 1.72× (below bar) | 2/4 → **0/4** |

The residual matched-gate fires on two seeds are `offdiag_cov` @ **backbone** — the genuine backbone liability Option B
already isolated (immature/low-diversity backbones carry correlated features), *not* an eval-set-cap artifact, so
matched-class eval correctly leaves it standing. This is the same "read at the projector only" verdict from a third
angle: the projector RankMe fire was an eval-set confound (removed once the eval set is matched), while the backbone
`offdiag_cov` fire is a real in-regime loss. The matched-class mechanism is the concrete Phase-1 carry — era eval sets
are few-class, so the era-comparison RankMe read must run against a class-matched reference.

## How to run

Each stressor pairs an atypical-healthy test arm against the canonical-healthy reference, seeds 0–3, probes off (cheap):

```bash
for stressor in low_diversity heavy_aug undertrained; do
  for seed in 0 1 2 3; do
    uv run python scripts/false_positive_stress.py stressor=$stressor seed=$seed \
      monitor.run_knn=false monitor.run_linear=false
  done
done
```

The verdict is the **inverted (quiet) gate**: every run should PASS with **no** instrument clearing its fire bar. Any
instrument that fires flags a false-positive boundary for that (instrument × surface × regime), recorded in the
envelope.

For the **Option B** ablation, add `collapse_pole=true` — this runs a third, matched forced-collapse arm in the same
stressed regime and emits the in-regime discrimination envelope + the `[collapse, healthy]`-axis positions alongside the
Option-A verdict (default `false` leaves the Option-A run byte-identical):

```bash
for stressor in low_diversity heavy_aug undertrained; do
  for seed in 0 1 2 3; do
    uv run python scripts/false_positive_stress.py stressor=$stressor seed=$seed collapse_pole=true \
      monitor.run_knn=false monitor.run_linear=false
  done
done
```

For the **matched-class eval** confirmation (A2), add `match_eval_classes=true` to the low-diversity cell — the
reference arm is then evaluated on the atypical arm's class subset, and the RankMe false fire should vanish at both
surfaces:

```bash
for seed in 0 1 2 3; do
  uv run python scripts/false_positive_stress.py stressor=low_diversity seed=$seed match_eval_classes=true \
    monitor.run_knn=false monitor.run_linear=false
done
```
