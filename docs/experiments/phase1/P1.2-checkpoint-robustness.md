# P1.2 checkpoint evaluation robustness — 2026-09-30

Status: protocol fixed before evaluating the new readouts. This is a diagnostic reuse of the five training seeds 3001,
3011, 3019, 3023, 3037, not independent confirmation. Compare full/last-block, with/without replay, and their common
train-only warm well. All original checkpoints and experiment artifacts remain read-only.

## Evaluation pools and pairing

Load the same attribute-valid BDD validation corpus at 64 pixels. Within each regime/scene cell, randomly reserve half
(floor) as queries with seed 41001; the remainder is a disjoint support pool. Both pools are fixed across every model,
draw, and budget. Record exact indices, class/condition names, counts and tensor hashes. This is index-level
disjointness, not a claim of perceptual duplicate removal. These validation images were used in earlier evaluations;
they are not an unseen test set.

Draw balanced support samples using seeds 41011, 41017, 41023. Budgets are 5, 25, 100 labels per scene class, nested
within each draw. Query images never train any head/backbone, select hyperparameters, or determine stopping. Fail if
support is insufficient. Select primary conditions using counts alone: >=30 queries and >=2 classes with >=5 queries.
Report every populated condition as sensitivity, including small ones.

## Fixed readouts

1. Frozen-feature cosine distance-weighted kNN, k=min(20, support size).
1. Frozen-feature logistic regression, support-only standardization, C=1, max_iter=1000. Same recipe as previous linear
    evaluation.
1. Genuine supervised few-shot fine-tuning: independently deep-copy the starting encoder, unfreeze ALL backbone
    parameters regardless of original online scope, initialize a fresh linear scene head with the same seed per
    draw/budget across models, and train 100 AdamW updates. Backbone lr=1e-5, head lr=1e-3, weight_decay=.05,
    batch=min(32, support size), no augmentation, clip norm=1. Uniform fresh random support minibatch each step; cross
    entropy only on support. Evaluate final update, no best-query selection. Record loss, support accuracy, and nonzero
    backbone parameter change. Frozen here means frozen DURING STREAMING: its copied encoder is also unfrozen for this
    downstream readout.

CPU, four Torch threads. No hyperparameter sweep. Save each cell and resume only against matching protocol, code, data
and checkpoint hashes. The warm model is evaluated once per draw/budget and shared across the five paired seed
contrasts.

## Outcomes and interpretation

Report sample-weighted query accuracy, global class-balanced accuracy (mean recall), mean accuracy across
count-qualified conditions, and all-condition sensitivity. Save individual predictions and per-condition results.
Average support draws WITHIN training seed; report paired Student-t 95% intervals across five seeds (df=4), conditional
on this warm well/query pool. Draws are not extra independent training seeds. Report all budgets/readouts and
replay/no-replay contrasts; no selecting a winning cell.

Primary diagnostic: last-block replay vs warm frozen, 25 labels/class, genuine fine-tuning, class-balanced global and
qualified-condition accuracy. Positive lower confidence limits for both would support a downstream advantage under this
fixed recipe only, not broad independent BDD superiority. All other contrasts/budgets are secondary and intervals are
nominal, not multiplicity-corrected. Inconclusive or negative results remain valid outcomes. Frozen-feature results
distinguish feature quality from downstream fine-tuning behavior. A single fine-tuning recipe is not an optimized
comparison. No new forgetting/BWT estimates: final checkpoints alone cannot reconstruct intermediate representations.
P1.3 recurrence and health-controlled selection remain subsequent experiments, not answered here.
