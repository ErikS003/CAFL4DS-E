# P1.2 replay advantage confirmation — protocol fixed 2026-09-27

This prospective experiment tests the positive result from the 2026-09-22 three-seed study. It does not tune the
training recipe or choose favorable seeds after observing results. Outcomes may support, contradict, or leave the
hypothesis unresolved; finite experiments do not prove a universal advantage.

## Hypothesis and scope

H1: the existing clean-warm TinyViT-MAE with reservoir replay improves global scene kNN accuracy AND macro-average final
scene-classification accuracy across driving conditions relative to its exact frozen initialization.

The claim is conditional on the existing seed-101 warm checkpoint, attribute-ordered BDD still-image stream, and 25
labeled support examples per class. It is not a claim about natural consecutive video, independently pretrained models,
new datasets, or all possible initialization seeds. Validation data have been used during development; this is
prospective replication on fresh training seeds and expanded validation panels, not an untouched benchmark test.

## Fixed design

- Five new training seeds: `2003, 2011, 2017, 2027, 2029`; all five run regardless of intermediate results.
- Warm checkpoint: `outputs/p1.2/wells/mae_bdd_train20_s101.pt`; hash recorded before execution.
- Same train-only warm partition (20%) and complementary single-pass training stream (80%); official val supplies only
    labeled evaluation data. Official test is unused.
- TinyViT, 64 px, full encoder updates, MAE mask ratio 0.75, AdamW learning rate `1e-4`, weight decay 0.05, update every
    incoming batch, reservoir capacity 256, 16 current + 16 replay once warm, training batch cap 32.
- B5 is an exact initial copy and receives no gradient updates. No no-replay arm is needed for this specific
    replay-versus-frozen hypothesis; reduced forgetting versus no replay is not tested by this run.
- Three fixed evaluation panels: reservation seeds `0, 20260927, 20260928`. Each has 25 support and 500 global query
    images per scene class (75 support / 1,500 queries for the current three-class val set). Up to 50 additional queries
    per regime/class cell; record actual counts and retain sparse regimes without hiding them.
- The seed-0 panel preserves the original support selection and expands the original global query set. Two additional
    panels test sensitivity to support/query sampling. Panels may overlap each other; they are not independent runs.
- kNN remains cosine-distance weighted with `k=20`; linear remains standardized multinomial logistic regression, `C=1`,
    maximum 1,000 iterations. No probe hyperparameter search uses these results.
- Health logging every 512 batches limits evaluation cost. Per-era linear accuracy is still recorded at every boundary
    on panel 0, including the final boundary. This logging change does not alter the update count or learning recipe.
- Save final model weights, resolved configuration, actual evaluation counts, per-seed outputs, and provenance.

## Decision rules, fixed before running

First average each metric over the three panels WITHIN each training seed. Then compute the five paired
online-minus-frozen differences. The independent replication unit is the training seed, never a condition or a panel.
Report two-sided 95% Student-t intervals across these five differences (`df=4`, critical value `2.7764451052`). These
intervals quantify training-seed variability conditional on this checkpoint, stream design and evaluation panels; they
do not quantify uncertainty over the entire BDD population or pretraining choices.

H1 is **supported** only if BOTH co-primary metrics have a 95% interval lower bound above zero, each is positive in at
least four of five seeds, and the mean kNN gain is at least 2 percentage points. Requiring both superiority tests forms
an intersection criterion. No alternative metric can rescue a failed co-primary endpoint.

H1 is **contradicted in this setting** if either co-primary metric has an interval upper bound at or below zero.
Otherwise H1 is **not established / inconclusive** (including a positive but smaller-than-2-pp kNN effect).

Report global linear accuracy, individual panels, individual conditions, frozen absolute accuracies, backward transfer,
and forgetting regardless of the verdict. A broader accuracy-superiority claim additionally requires a positive 95%
interval lower bound for global linear gain; a kNN-only win is explicitly described as such. Forgetting is a drop from
the online model's earlier peaks, not an advantage over the frozen model.

## Reproduction

From the repository root, with the existing dataset and warm checkpoint available:

```powershell
.\.venv\Scripts\python.exe -m scripts.confirm_replay_advantage
```

The runner records the protocol/config/checkpoint fingerprint before training, resumes only matching completed seeds,
and summarizes only after all five have completed. Machine paths can be supplied with `--bdd-root` and `--well`. Large
images and checkpoints remain under ignored local paths. The resulting small summary will be promoted with the final
interpretation once the experiment completes.
