# P1.3 — Warm-started BDD recurrence and retention

Protocol fixed before outcome inspection, 2026-10-01. This is a new controlled recurrence study, not an exact
replication of P1.2 or a real consecutive-video study. It does not duplicate the class-blocked STL-10 SimSiam study or
develop new filters/MoE.

## Question and controls

Does a warm-started MAE retain useful representations when a driving condition is absent, and recover when it returns?
Does reservoir replay help relative to no replay? Five fresh stream seeds: 5003, 5009, 5011, 5021, 5023. Four learned
arms per seed: recurrence/no replay, recurrence/replay, shuffled/no replay, shuffled/replay. One common warm-frozen
reference, paired to every arm, is evaluated on the same data.

A = clear-weather daytime; B = clear-weather night. Use A1-B1-A2-B2 with distinct training images in every visit. Both
domains retain the same scene classes. Classes are explicitly city street, highway, and residential (the three shared
evaluation classes). Parking lots are excluded: too sparse for matched visits and absent from the retained validation
classes. Source indices are recorded before and after this restriction. Metadata-only preflight gave 2,656 / 1,408 / 544
images per class per visit: 4,608 images and 144 updates per visit, 18,432 unique arrivals and 576 updates per arm. The
following count rule determines these quotas before any outcome is inspected. Per-class visit quota is min(4096,
floor(min(A count, B count)/2/32)\*32), at least 128; otherwise stop preflight, do not silently substitute domains. This
matches the scene histogram and length across all four visits without sorting images by scene within visits.
Labels/attributes construct the controlled benchmark only; no labels enter SSL, replay decisions, or optimizer updates.
This controls scene mix, not all nuisance factors. All train arrivals are from the existing disjoint 80% train
partition; the same train-only 20% warm checkpoint is reused. Official val supplies evaluation only; test is untouched.

Within each seed, each domain's candidates are randomly permuted and divided into two disjoint visits, then shuffled
within visit. The shuffled control globally permutes the EXACT same arrival indices once (no replacement). Pair both
policies to the same arrival order. Different seeds may reuse images; fresh seeds are not fresh datasets. Record full
indices, class names, counts, source hashes, model/config hashes and budgets.

## Training and observation

Existing TinyViT-MAE at 64 pixels, width 96, depth 4, mask ratio .75, full encoder and decoder updates. AdamW lr=1e-4,
weight decay=.05, constant LR, clip norm=1. Do not reset optimizer, model or memory at boundaries. Incoming and
optimizer batches are exactly 32 throughout, with no short boundary batches. Reservoir size 256, replay 16 sampled
before current admission; normally 16 current + 16 historical optimizer images. All arrivals enter the reservoir. At
first update use all 32 current images. No-replay uses all 32 current images. Equal arrival count, update count and
optimizer image exposures, but not identical current-image exposure or total wall-clock cost.

Every quarter-visit (plus step 0), evaluate frozen-feature kNN and standardized linear probes, RankMe and cosine drift
on fixed validation inputs. Preserve training RNG across all measurements. Health is passive, never fed back. Save full
method checkpoints at all four boundaries. At step 0 and boundaries also evaluate genuine few-shot fine-tuning of a
fresh encoder copy: 100 support-only AdamW steps, encoder lr=1e-5, head lr=1e-3, weight decay=.05, batch up to 32, clip
norm=1, no augmentation or query-based stopping. This is the existing checkpoint-robustness recipe. It never changes the
online model.

Fixed validation pool seed 51001. Reserve 50 support candidates per domain/scene cell, then up to 100 queries per cell
(minimum 30); fail if inadequate. No pool overlap. Three support draws (51011, 51017, 51023), 25 images per class: 12
from A and 13 from B, alternating which domain supplies 13 by draw. Same supports/queries for all seeds, arms and
checkpoints. Report per-domain class-balanced accuracy (mean class recall), their equal-weight mean, and sample-weighted
accuracy. No query labels fit any model. Names/index disjointness is not perceptual deduplication. Validation has been
reused in earlier studies, so this is fresh stream randomness, not independent dataset validation.

## Locked analysis

Let R(t,d) be domain d's class-balanced accuracy after visit t, with t=0 the warm well. Average support draws within
seed BEFORE inference. Primary readout is fine-tuning.

- Primary interference loss: L = ((R(1,A)-R(2,A)) + (R(2,B)-R(3,B)))/2. Signed: positive means degradation while the
    domain is absent; negative means improvement.
- Primary replay contrast: L(recurrence/replay)-L(recurrence/no replay), lower is better. A retention-success claim
    requires (1) no-replay L lower 95% bound >0, (2) replay contrast upper bound \<0, and (3) final equal-domain
    accuracy replay-minus- no-replay lower bound >-1 pp. Otherwise report which condition failed, including nulls.
- Separate downstream advantage: final replay-minus-warm accuracy with positive lower bound. This does not by itself
    demonstrate a replay benefit or a retention benefit.
- Secondary: signed BWT = mean(R(4,A)-R(1,A), R(4,B)-R(2,B)); signed best-prior-to-final forgetting over observations at
    boundaries after first exposure; return changes R(3,A)-R(2,A), R(4,B)-R(3,B); return-vs-first scores. Record each
    domain, not only averages.
- Secondary recovery latency on linear probes: first of TWO consecutive quarter-visit observations on the return visit
    at or above first-visit endpoint minus .5 pp. Include the return start. If unmet, report null/censored, not zero.
    Always show first-visit gain versus warm: apparent retention of an unlearned domain is not successful learning.
- Secondary order contrasts compare recurrence versus shuffled at matched checkpoints, and replay versus no replay
    within shuffled. Shuffled quarter boundaries are matched sample-count markers, not actual regime transitions. No
    biological/task forgetting interpretation is assigned to shuffled temporal differences alone.

Paired Student-t 95% intervals across five seeds; n=5, never n=15. All secondary intervals nominal, no picking the best
metric or retuning pressure until significant. The common warm checkpoint and fixed queries limit generalization. Every
arm and seed remains in the report. Even a positive result does not prove permanent erasure, general BDD superiority, or
a calibrated health controller. Findings contribute to P1.3/P1.5; subsequent signal validation is separate. No new
filters or MoE in this study.

## Execution and preservation

Driver: `python -m scripts.run_recurrence_retention`. Config overrides use repeated `--override key=value`; defaults
identify the existing local BDD installation and well. Default output:
`outputs/adaptation-bdd/recurrence-retention/20261001`. Completed arms may be reused only against matching input/data
locks; partial arms are rejected, not overwritten. Save individual predictions, trajectories, losses, checkpoints,
summary JSON/Markdown and plots. No commit/push or dataset download is part of this run. Temporary idle-sleep prevention
requires separate user approval and is released on exit.
