# Cached night-loss diagnostic after notebook39

This is an explicitly exploratory analysis requested after seeing notebook39's
aggregate outcomes. Future4 and its night guard failure are already known. One
branch record was inspected for its schema before this declaration. The choices
below are fixed before computing this diagnostic's derived results; they are not
a preregistration on unseen data and do not revise any previous gate.

Use only saved notebook39 predictions, verified correctness arrays, labels/roles,
health readings, raw-bank provenance and per-update traces. No SSL, fitting,
encoding, downloads, new labels or data deletion. Use NumPy/CPU and four BLAS
threads. Preserve original sources and outcomes; separate output <=64MiB and
768MiB disk reserve. Notebook40 will contain checked scientific figures and an
executed saved-result reconstruction.

Include both ages512/4096, both current/half-replay diets, all three histories,
all four futures, all12 paired support draws and both128/512 capability landmarks.
Fine-tuning remains the primary procedure; kNN and frozen linear are separate
diagnostic outcomes, never alternative primary winners. Reconstruct all102 jobs'
correctness from the original1,224 panels and match the original cached arrays.

Report absolute parent/post accuracy, parent-relative gain, newly wrong versus
newly correct query rates, and class-specific city/highway effects within each
domain. Aggregate classes equally within domains, domains equally overall,
histories/futures/support draws equally. Retain full support-level tables. For
each case/class save query-level loss/gain support counts, persistent transitions
(>=9 of12 draws), fractions with net loss and the share of positive per-query net
loss concentrated in the largest10% of query identities. Concentration is a
descriptive, outcome-selected distribution summary, not a selected evaluation set.
Display all contexts; highlight future4 without excluding or rescuing any case.
Report leave-one-history future4 night effects and support-draw sensitivity.

Signals at each origin are all five existing parent-relative health changes on
both fixed banks, plus cumulative and trailing16-update means of loss,
pre-clipping gradient norm and actual encoder parameter-step L2. Sum of step L2
is a parameter path length, not net parameter displacement; record it separately.
Do not assign a beneficial sign to geometry movement. Do not create new sensors,
thresholds, calibrators, residual regressions or controllers.

Correlations use twelve case means (3 histories x4 futures), separately within
each age/diet. Average supports first; do not count support draws, the two banks
or checkpoints as independent learners. Report Pearson and average-tie-rank
Spearman, no p-values or confidence claims. Five assays are fixed:

- origin16 versus terminal512 night loss;
- origin128 versus contemporaneous128 night loss;
- origin128 versus terminal512 night loss;
- origin128 versus remaining128-to512 night loss;
- origin512 versus contemporaneous512 night loss.

Loss is minus parent-relative gain (positive means damage). Repeat for night
city/highway individually. Report every signal in fixed order, both coefficients,
and all three leave-one-history and four leave-one-future coefficients (n8/9).
These deletions describe dependence on groups, not held-out predictive validation.
Compare bank agreement for matching geometry fields within each age/diet/origin.
No pooled correlation across ages/diets/checkpoints, best-signal search or causal
mediation claim. Temporal precedence alone does not establish prediction transfer.

Independent checks reconstruct all effects from saved panels, reconcile original
summary values and the future4 guard, verify loss/gain accounting, compute
correlations with SciPy rather than the analysis rank implementation, and check
all group-deletion rows. Synthetic fixtures exercise class weighting, tied ranks,
constant signals, transitions, temporal windows and the complete report path.
Pin code/config/declaration/tests and all consumed inputs before analysis.

Deliver source/context/class/checkpoint/support tables, signal/correlation tables,
query transition counts, six figures and an explanation of supported patterns and
competing hypotheses. Further training and the larger health-mechanism study
remain unlaunched. Any suggested mechanism is a hypothesis for a new design.
