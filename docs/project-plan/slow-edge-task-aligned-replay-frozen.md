Freeze this document and collector source hashes before measurements. No response-model fitting, query-based calibration, or choice retuning is permitted.

Use all twelve saved transition parents from the corrected replay-local study, and the pure incoming order and fixed current/replay selection from the controlled training-RNG study. Actions are 8/16/24 replay images in a 32-image batch. New primary branches take one update with training seeds from repeats 4 and 5. The corresponding already-inspected six-update embeddings are reused only as a secondary horizon diagnostic. Images, labels, parents and all support/query panels are reused; the new one-update outcomes are fresh measurements, not independent dataset confirmation.

Three cyclic rotations are (head-fit, task-gradient, third-support-check) = (support1,support2,support3), (support2,support3,support1), (support3,support1,support2). Fit each parent logistic head at fixed C=.1 with fitting-only normalization. Compute balanced task CE gradients on the second support, never query labels. The third support is disjoint from both head fitting and the corresponding task gradient; it is used only for outcomes for that rotation. Since the three rotations use every support for gradients, it is not globally untouched by the ensemble policy.

On each candidate selected SSL batch, use two isolated observation seeds 111003 and 112009, independent of trajectory seeds. Compute (1) the encoder SGD delta -1e-4 times the SSL gradient after clipping the GLOBAL method gradient at norm1; (2) the encoder delta from a copied AdamW step using stored parent moments, actual clipping and weight decay. Forecast CE reduction as minus the dot product of task gradient and delta, averaging the two observation draws. Cosine is descriptive only. Save directions and task gradients for audit. Virtual optimizer calls are counted separately from trajectory updates. Copies and forked RNG must preserve parent weights, optimizer tensors, module modes, assigned gradients and global RNG.

Report both pooled probe and mean disjoint-support probes; do not select a reader using query results.
