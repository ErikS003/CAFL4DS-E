# Frozen replay recipe: order and stochastic replication

Freeze the unguarded, accuracy-guided health-plus-gradient response models from the six-update controller study. It is a candidate with small pooled average gains, not an established working controller. Use the existing whole-original-pool held-out model for each parent; never refit or select regularization on new outcomes. Freeze composition and reconstruction models and the accuracy training constant from the same study as baselines. Include constant16 as a reference.

From all twelve transition parents, create two new arrival conditions using deterministic new permutations of previously unseen-within-trajectory images: six batches of the incoming domain; and six batches with domain pattern incoming/outgoing/incoming/outgoing/incoming/incoming (two interruptions). Preserve the first ten batches and retain a unique permutation of the full768-image stream pool. The interleaved condition uses only64 outgoing images because some parent histories leave exactly64 unused outgoing images; it tests transfer outside the pure-domain response-training regime, without giving the controller future order. Do not interpret condition differences as a randomized domain-only effect: their selected image subsets differ.

Recompute label-free observations before the first new batch, using the same96-image monitor, two-mask gradient recipe and reconstruction diagnostics. For each condition use two new sampling/augmentation seeds. Save all48 sets of predictions and policy choices before training any branch. The input recipe, fitted parameters, baseline constants and linear-reader regularization remain frozen. No new outcome may change a choice.

Train all8/16/24 allocations for six updates,144 branches and864 new optimizer updates. Deep-copy optimizer state at every restore, keep optimizer batches exactly32 images, preserve action-independent all-arrival256-image memory, and audit nested sampling and observation immutability. Fit fresh linear probes on each branch's representations using labeled support only: pooled plus three disjoint supports, accuracy-selected C as primary, CE-selected and fixed C=.1 as sensitivities. Query labels never enter SSL updates, controller features or response-model fitting. Score balanced linear-probe accuracy, day/night accuracy and CE on both reused query panels. Cache embeddings for independent readout reproduction.

Primary replication is the new shuffled pure incoming-domain condition, pooled accuracy-selected reader, both queries. A generalization claim requires positive accuracy increments over the frozen training constant AND both composition/reconstruction policies, with gains across all three original pools, supports and both new draws, and nighttime retention. Report interleaved transfer separately, including failures. Average gains and negative slices must both be visible; two draws and three reused pools do not justify precise population confidence intervals. Frozen model/pool exclusion, predicted choices, raw readouts, paired comparisons and training budgets must be independently replayed.

This is broader stochastic/order replication on reused data and parent states. It does not establish fresh-dataset transfer, new-task transfer or repeated-decision closed-loop MPC. If it passes, test repeated fresh observations next; if it fails, retain the result and diagnose whether the response target, features or unknown future order limit transfer.
